# إدارة المحتوى بمراجعة بشرية

هذه الدفعة تقابل فرع `codex/manual-editorial-review` في مستودع back. نقطة البداية: `d45aac22256f75513b581328e2043c74c6d23772`.

## سير العمل

1. افتح «صحة المحتوى»، وحدد الصفحة والمشكلة.
2. افتح المحرر وصحح النص أو التصنيف أو المرفق. الحفظ يلتزم بقيم الوصف والكلمات المفتاحية التي راجعتها، بما فيها القيم الفارغة.
3. عند الحاجة، اطلب اقتراحًا مساعدًا. إنشاء الاقتراح منفصل عن حفظه على المحتوى.
4. افتح طابور الاقتراحات، واقرأ مقارنة النسخة الحالية والمقترحة، وافحص مطابقتها للمرفق ثم اعتمد أو ارفض كل اقتراح. الرفض الجماعي متاح؛ الاعتماد الجماعي محظور في الواجهة ومسار الطلب.
5. بعد الاعتماد راجع الصفحة العامة ووسوم SEO. طلب الاعتماد يبطل كاش المحتوى في الفرنت اند.

## تنظيم الصفحات

| المسار | القرار |
| --- | --- |
| `/dashboard/content-quality` | المدخل الرئيسي: الحالة، الفهرسة، وفتح المحرر |
| `/dashboard/quality?tab=content` | تفاصيل المشكلات ومراجعتها؛ تبويب المحتوى هو الافتراضي |
| `/dashboard/content-audit/ai-operations` | اقتراحات اختيارية، مقارنة فردية، ومتابعة العمليات |
| `/dashboard/content-audit` | تحويل إلى المدخل الرئيسي مع الاحتفاظ بمعاملات الرابط |
| `/dashboard/content-audit/readiness` | تحويل إلى تفاصيل المحتوى مع الاحتفاظ بالفلاتر |
| صفحات التشابه والتلف والمخزون وSearch Console | وظائف متخصصة باقية؛ لا حذف للبيانات أو الصفحات العامة |

أزيل تحويل content-audit العام من إعداد Astro لأنه كان يحجب صفحات مراجعة قائمة. التحويلات البديلة صريحة ومحمية بالمصادقة.

مسارات `autofix` وطلبات `auto_apply` القديمة تنشئ معاينات فقط. مسار `content-quality/fix` القديم يرد بـ409 ويوجه المحرر للمراجعة بدل توليد النص وحفظه مباشرة. صلاحية المدقق وحدها لا تكفي لاعتماد نص على مقال أو منشور؛ الباك اند يتحقق من صلاحية إدارة نوع المحتوى والدولة.

## نتائج التحقق

- نجحت اختبارات Node الـ22، بما فيها منع وصول الاعتماد الجماعي والتوليد مع الحفظ إلى الباك اند، وتحويل طلبات الدفعات القديمة، والحفاظ على الحقول التي راجعها المحرر.
- نجح `astro check`: صفر أخطاء وصفر تحذيرات، مع تلميح واحد غير مانع.
- نجح بناء الإنتاج بإعدادات محلية، ونجح `npm run smoke`: ثمانية فحوص HTTP عامة/أمنية وخمسة فحوص للوحة المراجعة والتحويلات. يستخدم الاختبار API محليًا اصطناعيًا، وليس حسابًا أو قواعد إنتاج.
- يظل فحص اعتماد اقتراح فعلي مع قواعد الدول والصلاحيات وSEO على بيئة اختبار مطلوبًا قبل الدمج والنشر.

## حدود هذه الدفعة

تبقى الفحوص التقنية وقرارات السياسات الحالية. لا تُصلح هذه التغييرات النصوص المنشورة تلقائيًا، ولا تثبت حقوق المرفقات ولا تضمن قبول AdSense. العمل التحريري المطلوب: تطابق عنوان الصفحة وتصنيفها وشرحها مع الملف، معالجة التكرار بحسب الغرض، وإضافة أدلة أصلية مفيدة للقارئ دون حشو أو حد كلمات مصطنع.
